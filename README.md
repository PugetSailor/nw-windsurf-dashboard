# NW windsurf dashboard

Where to sail in the Pacific Northwest this week: star ratings for ~74 spots from NWS, Environment Canada and local
forecasts, gear picks, and a track record of how past forecasts did.

Live page: https://pugetsailor.github.io/nw-windsurf-dashboard/

This repo holds only the built page. It is generated by `python -m nww public` in a separate private repo; don't edit
`index.html` here by hand.
